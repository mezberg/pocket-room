# Pocket Room

Your flat in 3D. Any piece of furniture you see (a shop photo, a screenshot) is built in 3D, dropped into
your room to scale, checked against the room's rules, and you can talk to your room about it.

OpenAI: Vision · Decisions API · Realtime voice · gpt-image.

## Repo
- `pocket-room-notes/`: Obsidian vault with the project board (`Pocket Room board.canvas`): parts, risks,
  demo script and the development plan.
